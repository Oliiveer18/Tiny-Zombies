# Tiny Zombies
`npm install && npm run dev` · `npm run build` (salida en dist/).
Sustituye modelos: copia tus GLB de Meshy a public/models/ con los nombres de src/models.config.js
(player, zombie, runner, tank, fence, barrel, barrier, crate, sack, car). Ajusta scale/offset/clips allí.

Proyecto en fase de DISEÑO hacia un juego de supervivencia de mundo abierto. Empieza por `CLAUDE.md`, `docs/CONTINUAR.md` y `coordinacion/LEEME.md`.
