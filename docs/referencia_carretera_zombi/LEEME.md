# Referencia: proyecto Carretera zombi / Endless Aftermath

> ⚠️ Estos documentos nombran a Oli y Lali. En ESTE juego Oli y Lali NO existen: se ignoran todas sus menciones (personajes, menús, coop, arte, modelos).

Copia de los documentos de diseño del otro proyecto del usuario (HD-2D por casillas, Three r128, un solo archivo). Sirve para CONSULTAR ideas y decisiones; no es el motor de este juego. Lo que manda para el juego nuevo es `../DISENO.md`. Si algo choca, gana `../DISENO.md`.

- `IDENTIDAD.md`: visión, pilares, NPC y roles, zonas por distancia (esta última NO se usa), inicio.
- `MUNDO.md`: 40 lugares con botín y NPC, olas de trabajo, vehículos, animales, recursos.
- `CONSTRUCCION.md`: recursos, piezas, estancias, crafteo, progresión del refugio, inicio de partida.
- `DISENO.md`: diseño completo original (agua realista §7c, estructura del mundo §7b, armas, necesidades). Incluye cosas descartadas aquí: «el mundo se endurece con el tiempo», autoapuntado, muerte total.
- `PANTALLAS.md`: menús y primera sesión.
- `ARTE.md`: dirección artística del otro proyecto (diorama realista envejecido). El aspecto de ESTE juego es el de Tiny.
- `mapas/carretera_prueba.json`, `carretera_ejemplo.js`: ejemplo de datos de mapa y de generación de carretera por calcomanía.
